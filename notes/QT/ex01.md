```cpp
class Person : QObject {
public:
    explicit Person(QObject *parent = nullptr) : QObject(parent) {
        cout << __PRETTY_FUNCTION__ << endl;
    }
    ~Person() override {
        cout << __PRETTY_FUNCTION__ << endl;
    }
};
```

### `class Person : QObject`

- **继承自 `QObject`**：`QObject` 是 Qt 中所有对象的基类，提供了信号槽、对象树（父子关系）、事件处理等核心机制。
- 注意这里用的是**私有继承**（默认 `class` 继承为 private）。虽然能编译，但通常我们写 `class Person : public QObject`。私有继承会阻止外部把 `Person*` 当作 `QObject*` 使用，从而失去很多 Qt 特性。**建议改为 `public QObject`**。



explicit：禁止隐式转换。防止写出 `Person p = someQObjectPtr;` 这种意外的隐式构造，也防止函数传参时的隐式类型转换。

### 3. 析构函数

cpp

```
~Person() override
```



- **`override`**：C++11 关键字，明确表示"我要重写基类的虚函数"。`QObject` 的析构函数是 `virtual` 的，所以这里合法。`override` 的作用是**让编译器检查**：如果基类没有对应的虚函数，会直接报错，防止写错签名。
